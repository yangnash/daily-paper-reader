## 摘要
复杂场景中的动作识别通常涉及多个并发的细粒度动作，这使得对内部动作结构的建模具有挑战性。现有大多数方法依赖于整体表示，这不足以捕捉细微的交互和细粒度语义。虽然近期基于提示的方法引入了解耦，但缺乏明确的语义引导，而仅基于视觉或结构化线索的方法仍较为粗粒度。在本文中，我们提出了基于原子动作的知识引导解耦（KDA），利用细粒度语义知识增强动作表示并实现更精确的解耦。具体来说，我们使用大语言模型（LLMs）将动作标签分解为原子动作，提供明确的时空语义。知识注入模块（KIM）首先将原子动作知识整合到视频特征中。基于这一增强表示，知识解耦模块（KDM）进一步解耦原子动作知识，为动作解耦提供更精确的语义引导。我们引入了一种知识解耦损失（KD Loss），以促进KDM内知识组件的更清晰解耦。大量实验表明，KDA提高了特征判别性，并在多标签动作识别基准上取得了最先进的性能。此外，KIM和KDM可以轻松集成到其他方法中，展示了强大的通用性。

## Abstract
Action recognition in complex scenes often involves multiple concurrent fine-grained actions, making it challenging to model internal action structures. Most existing methods rely on holistic representations, which are insufficient for capturing subtle interactions and fine-grained semantics. While recent prompt-based approaches introduce disentanglement, they lack explicit semantic guidance, and methods based solely on visual or structured cues remain coarse-grained. In this paper, we propose Knowledge-guided Disentanglement with Atomic Actions (KDA), which leverages fine-grained semantic knowledge to enhance action representations and enable more precise disentanglement. Specifically, we use Large Language Models (LLMs) to decompose action labels into atomic actions, providing explicit spatial-temporal semantics. A Knowledge Injection Module (KIM) first integrates atomic action knowledge into video features. Based on this enhanced representation, a Knowledge Disentanglement Module (KDM) further disentangles atomic action knowledge to produce more precise semantic guidance for action disentanglement. A Knowledge Disentanglement Loss (KD Loss) is introduced to encourage clearer disentanglement of knowledge components within KDM. Extensive experiments demonstrate that KDA improves feature discriminability and achieves state-of-the-art performance on multi-label action recognition benchmarks. Moreover, KIM and KDM can be readily integrated into other methods, demonstrating strong generality.

## 1. 核心问题与整体含义

- **背景**：复杂场景中的动作识别常涉及多个并发、细粒度的动作，例如一个人同时“看电视”和“拿起电话”。这类多标签、多交互场景要求模型不仅识别整体动作，还要理解内部结构、对象交互与语义边界。
- **现有挑战**：
  - 传统基于整体表示的方法（2D/3D CNN、ViT）难以建模对象间复杂交互和多个叠加动作。
  - 基于空间-时间场景图（SSG）的方法依赖场景图注释（SGA），语义颗粒度粗，且不适合动态动作。
  - 基于可学习 prompt 的解耦方法（如 ProDA）缺乏显式语义知识；仅靠视觉线索难以拉开相似动作的特征间隙。
  - 视觉-语言方法（如 CLIP）受限于粗粒度标签注释。
- **核心问题**：如何将细粒度、显式的语义知识引入动作表征与解耦过程，以提升复杂多动作场景下的识别可判别性。
- **整体贡献**：提出 **KDA（Knowledge-guided Disentanglement with Atomic Actions）**，利用大语言模型（LLM）将动作标签分解为“原子动作”，以显式时空语义指导知识注入与动作解耦，在特征、结构、语义三个层级实现层次化解耦。

## 2. 方法论

### 2.1 核心思想
- 利用 LLM 将每个动作标签分解为若干具体的、带时空信息的原子动作描述（如“人弯腰”、“伸手拿电话”、“握住电话”），并编码为文本嵌入，组织成“原子动作记忆库”（Atomic Action Memory Banks, AMBs）。
- 在 SSG 基础上进行两级知识操作：
  1. **知识注入**：用原子动作知识增强节点特征；
  2. **知识解耦**：在动作规范（Action Specification, AS）约束下，从增强特征中精确分离指定动作与未指定动作的语义。

### 2.2 关键技术细节

**（1）动作规范（Action Specification, AS）**
- 将动作标签转换为多热向量：指定动作提示（SAP）和未指定动作提示（UAP），UAP 为 SAP 在全标签空间中的补集。
- 引入“干扰类”（distractor classes）防止模型过度依赖标签先验；生成含 0 到 N 个真实标签、固定长度的 SAP/UAP 对。

**（2）知识注入模块（KIM）**
- 对每个节点特征，通过评分网络计算与各记忆库中原子动作的相关性得分。
- 使用阈值二值化生成选择向量，并采用 Straight-Through Estimator（STE）配合 sigmoid 代理梯度保证可微性。
- 通过矩阵乘法检索选中的知识，拼接后经 MLP 自适应聚合，以残差方式注入节点特征：
  \[
  f_{i}^{j} \leftarrow f_{i}^{j} + \mathrm{MLP}([z_1; z_2; \dots; z_K])
  \]

**（3）知识解耦模块（KDM）**
- 在 AS 约束下进行受限知识检索：\(\tilde{\delta} = \delta \odot p_{as}\)，只保留指定动作相关原子知识。
- 为避免强语义主导，引入可学习嵌入矩阵 \(E_k\) 与记忆库并列，将检索知识与可学习嵌入拼接融合：
  \[
  \hat{z}_k = \mathrm{MLP}([z_k; e_k])
  \]
- 使用 \(M\) 个解耦头将融合知识分解为细粒度组件，再根据节点特征动态加权聚合：
  \[
  g_{as} = \sum_{m=1}^{M}\alpha_m h_m,\quad \alpha = \mathrm{MLP}([f; h_1;\dots;h_M])
  \]
- 对 SAP 和 UAP 分别执行该流程，得到互补引导特征 \(\hat{f}_{SAP}\) 和 \(\hat{f}_{UAP}\)，送入 VGPNN 做关系推理。

**（4）损失函数**
- **分类损失** \(L_{cls}\)：对 UAP、SAP、融合表示分别做 BCE，保证信息完整性。
- **动作解耦损失** \(L_{ad}\)：采用 ProDA 的风格，最小化 UAP 与 SAP 引导特征之间的 Pearson 相关性，并加入重构损失保持原始信息不丢失。
- **知识解耦损失** \(L_{kd}\)：引入可学习语义锚点 \(U\)，以 margin 截断的相似度 \(s(\hat{h}_m, \mu_l) = \min(\hat{h}_m^\top \mu_l, \gamma)\) 来对齐共享信息，同时以其他解耦头作为负样本促进头间相互独立：
  \[
  L_{kd} = -\frac{1}{M}\sum_{m=1}^{M}\log\frac{\sum_l \exp(s(\hat{h}_m,\mu_l)/t)}{\sum_l \exp(s(\hat{h}_m,\mu_l)/t)+\sum_{n\neq m}\exp(\hat{h}_m^\top h_n/t)}
  \]
- 总损失：
  \[
  L_{total} = L_{cls} + \lambda_1 L_{ad} + \lambda_2 L_{kd}
  \]

## 3. 实验设计

### 3.1 数据集与基准
- **Charades**：多标签动作识别，9848 个视频，157 类，平均每个视频 6.8 个动作，衡量指标为 mAP。
  - 标准协议：使用预测 SSG（LaIAR 视觉特征，R101 骨干）。
  - Oracle 协议：使用人工标注 SSG（CLIP B/16 视觉特征）。
- **SportsHHI**：人体-人体交互分类（HHICls），来自篮球/排球视频，34 个交互类别，指标为 mAP、R@50、R@20。
- **Action Genome**：用于 SSG 注释基准（后台支持），未直接用于最终测试。

### 3.2 对比方法
- Charades：I3D、VideoMLN、STRG、SGFB、OR2G、LaIAR、ProDA、VicTR，以及各自的 Oracle 变体。
- SportsHHI：STTran、HORT、ACARN、SlowFast、SportsHHI 官方基线（SlowFast-R50 / VideoMAE 骨干）、ProDA 等。
- 还做了参数匹配的对照实验，以确保公平比较。

### 3.3 主要结果
- **Charades Oracle**：KDA 获得 73.2 mAP，显著超过 ProDA（71.1）与 VicTR（50.1）。
- **Charades 标准设定**：KDA 为 49.9 mAP，与 ProDA（50.2）相当（两者均明显优于其他非解耦方法）。
- **SportsHHI**：在 VideoMAE 骨架上，KDA（+KIM & KDM）达到 11.70 mAP，比基线（10.69）提升 +1.01；同时 R@20 从 43.72 提升至 48.52。

## 6. 主要结论与发现

- **原子动作知识能显著提升解耦质量**：相比纯可学习 prompt，原子动作提供显式时空语义，使特征间距更大、解耦更精细。
- **KIM 增强特征、KDM 精化解耦**，两者协同比单独使用任一模块效果更好；KD Loss 进一步促进解耦头间独立性，且 margin 约束避免过对齐，提升鲁棒性。
- **可插拔性**：KIM 和 KDM 可直接嵌入现有方法（如 SlowFast、SportsHHI 基线、VideoMAE），普遍获得性能提升。
- **领域泛化性**：在跨场景域偏移测试中，KDA 平均准确率最高（65.1），且最低准确率也优于其他方法。
- **LLM 选择的稳健性**：不同 LLM（Qwen3-plus、GPT-5.5、Opus-4.8）结果接近，说明 KDA 不依赖特定 LLM；结构化 prompt 优于非模板 prompt。

## 7. 优点

1. **语义显式性**：利用 LLM 产生细粒度原子动作，比可学习 prompt 或标签提供更丰富的时空语义，增强模型理解能力。
2. **层次化解耦设计**：特征级（KIM）、结构级（KDM）、语义级（KD Loss）三个层级协同，逻辑清晰、设计完整。
3. **模块可移用性强**：KIM/KDM 不依赖特定主干，可即插即用，具有很好的通用性，且实验证明在多种骨架上有效。
4. **损失函数设计合理**：KD Loss 结合语义锚点、margin 截断与负样本对比，既维持共享语义又鼓励头部独立，缓解语义坍塌。
5. **实验全面**：包含多个数据集、多种协议、大量消融和效率分析，特别是对解耦头路由行为的统计揭示模型容量与语义分配的内在机制。
6. **严谨的公平性处理**：SportsHHI 上构造参数匹配的基线，避免“参数多而结果好”的质疑。

## 8. 不足与局限

1. **依赖 SSG 质量**：在标准设定（预测 SSG）下性能提升有限（Charades 上与 ProDA 持平），说明错误的目标检测/关系预测会削弱原子知识的效果；论文也承认 SSG 质量是知识引导解耦的重要前提。
2. **跨模态特征不对齐**：Charades 标准设定中文本编码器（CLIP）与视觉骨干（ResNet-101）不匹配，限制了知识迁移效率，但论文未深入解决这一问题。
3. **语义过强的风险**：原子动作具有较强先验，若使用不当可能淹没视觉信息（消融 A/B/C 显示仅用原子动作时性能下降），需要依靠可学习嵌入来平衡，说明该方法对超参和结构比较敏感。
4. **实验范围有限**：仅在 Charades 和 SportsHHI 两个数据集上验证，未覆盖如 AVA、Something-Something 等更广泛的动作识别基准；多标签场景是重点，但未见零样本（ZSL）或开放词表实验。
5. **效率开销**：KDM 需要两次前向传递（SAP/UAP），增加推理延迟约 40%（0.030s→0.042s）；原子动作生成依赖离线 LLM，虽测试时无额外 LLM 调用，但部署位置记忆库的存储与检索开销需额外考虑。
6. **缺少统计显著性检验**：部分消融差异较小（例如 head=10 与 12 相差仅 0.08 mAP），未报告多次运行的标准差（域偏移实验除外），可能难判断差异是否显著。
7. **KD Loss 的超参（margin、温度、锚点数）敏感性分析不足**：论文仅固定部分数值，未系统讨论这些超参的敏感性。
